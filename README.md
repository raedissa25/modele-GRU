Ce projet présente un modèle de classification des signaux ECG basé sur un réseau de neurones récurrents de type GRU (Gated Recurrent Unit), une architecture efficace et légère pour le traitement de séquences temporelles. Utilisé sur des signaux issus de la base de données MIT-BIH, ce modèle permet de capturer les dynamiques temporelles complexes tout en étant moins coûteux en calcul que les LSTM classiques.

Le dépôt inclut le code source du modèle, les notebooks d’entraînement et de test, ainsi que des résultats visuels représentatifs des performances obtenues (courbes d’apprentissage, matrice de confusion, rapport de classification).

Les objectifs du projet incluent :

Le traitement et l’organisation séquentielle des signaux ECG.

La conception et l'entraînement d’un modèle GRU optimisé pour les données biomédicales.

L’analyse des performances du modèle sur des signaux ECG bruts et prétraités.

La visualisation claire et précise des résultats pour interprétation.

Le dépôt est structuré comme suit :

📁 résultats : courbes d’apprentissage, rapport de classification, matrice de confusion, distribution des classes.

📁 modéle finale : fichier .h5 contenant le modèle GRU entraîné.

📁 entrainement et évaluation du modéle : notebooks d’entraînement, de test, et d’analyse des prédictions.
